## Postagem automática: o que dá e o que não dá
| Plataforma | Automático? | O que você precisa |
|---|---|---|
| YouTube | Sim, `clipper/upload.py` | Credencial Google (passo 5). Público só após auditoria da API; antes disso, fica privado. |
| TikTok | Parcial | App no TikTok for Developers + aprovação (posts via API ficam privados até a auditoria). Até lá: subir pelo app. |
| Instagram Reels | Parcial | Conta profissional ligada a uma Página do Facebook + app Meta. A API pede o vídeo em um link público. Até lá: subir pelo app. |

Os mesmos cortes verticais servem nas três. Os textos (legenda e hashtags) são adaptados por plataforma na hora da postagem.
